# MTS ID Fun — Telegram demo bot

A demonstration-only queue bot. It uses synthetic IDs such as `DEMO-123456` and a test code generated by the bot itself. It does **not** collect real phone numbers, SMS codes, passwords, or account login data. The “payment” feature only records a manual status; it does not transfer money.

## Features
- Client menu and queue position
- Admin notifications with Accept / Reject / Contact buttons
- Admin requests a synthetic test code generated by the bot
- User enters the test code; admin can mark the request completed or rejected
- Optional required channel subscription
- Owner statistics at `/admin`
- SQLite database

## Setup
1. Create a bot with `@BotFather` and copy its token.
2. Get your Telegram numeric user ID using a trusted ID helper bot or your own Telegram tooling.
3. Add the bot as an administrator to the channel so it can check membership.
4. Copy `.env.example` to `.env` and fill in `BOT_TOKEN`, `ADMIN_ID`, and `CHANNEL_USERNAME`.
5. On a Python host, install dependencies and start:
   ```bash
   pip install -r requirements.txt
   python bot.py
   ```

## Free hosting note
GitHub stores the code but does not continuously run a Telegram polling bot. You need a host that supports a long-running Python process. Check the host's current free-tier limits before deploying. Keep `.env` private and never upload the bot token to GitHub.

## Important
This project is a simulation. Do not modify it to request real SMS/Telegram login codes or to trade access to phone numbers/accounts. The bot does not make real payouts.
